# ESCJ CONECTA

Portal institucional público de la Unidad Educativa Esclavas del Sagrado Corazón de Jesús (UE-ESCJ CBA), construido con Astro y TypeScript.

## Desarrollo local

Requiere Node.js y npm instalados.

```sh
npm install
npm run dev
```

Abre la dirección local que muestre Astro en la terminal (normalmente `http://localhost:4321`). Para generar la versión de producción, ejecuta `npm run build`; para previsualizarla, ejecuta `npm run preview`.

## Recursos institucionales

La portada usa marcadores de texto para el escudo, los logotipos y las fotografías que todavía no se han proporcionado. Sustituir esos marcadores por recursos oficiales autorizados antes de publicar el portal. Noticias, actividades y proyectos aparecen vacíos hasta contar con información confirmada.
